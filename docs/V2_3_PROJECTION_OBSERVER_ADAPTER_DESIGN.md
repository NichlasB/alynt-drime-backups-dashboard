## Decision and trust boundary

Proceed with an isolated socket-free composition candidate, NOT attachment to
the existing relay/worker. The current passive sink catches exceptions/ignores
returns but exposes mutable Buffers; it is not an arbitrary-observer security
membrane. A new fixed owner must detach bounded bytes before deferral and never
return them or accept caller callbacks/decoder providers. It calls the existing
zero-row decoder directly; unchanged old native source groups stay unchanged.

Identity labels and synthetic forwarding calls are not real provenance. Genuine
limited-account authentication/grants, endpoint coverage, installed source/profile,
forwarding equality and full process/storage/cost closure remain unproved/A1-A4
Blocked. Never compose self-reported model labels into a native success receipt.
No actual authentication, SQL, network, storage, worker or wiring operation.

## Finite eight-task plan

1. This design: own scope, trust boundaries, order and acceptance below.
2. Detached byte owner: exact context, bounded private snapshots, opaque one-use
   credits and fixed decoder call. Caller mutation after capture cannot alter the
   selected bytes; no raw byte/handle escape or arbitrary observer callback.
3. Synthetic session binding: selected three-packet greeting/limited-user hello/
   canonical OK profile, same owned seed/schema/private session. Strict sequence,
   flags and thread correlation; unknown/reconnect/root/verifier input refuses.
   This is consistency of invented bytes, never authentication/grant proof.
4. Synthetic forwarding credits: capture, exact-byte completion acknowledgement,
   then ordered observation. Wrong/reused/partial/foreign/out-of-order credit
   poisons the owner. Neither acknowledgement nor parser return controls transport.
5. Terminal closure: both directional EOFs, no pending credits, exact selected
   result and one-shot finish under the original deadline; traffic after EOF
   refuses. Model closure is not actual socket/process/shutdown closure.
6. Resource accounting: bounded cumulative copied bytes, queued byte/item peaks,
   disposal and truthful frozen scalar accounting. No deadline refresh or copy
   budget reset, no physical memory/process budget claim.
7. Adversarial review/tests: controls must expose guard removals at actual module
   boundaries; malformed profiles, mutation, replay, order and shutdown failures
   cannot pass through a refusal-only or mocked unit-under-test path.
8. Source-scoped readiness reconciliation: verify fixed imports/dormancy, final
   canonical Light/Security and tests, plan/owning evidence and exact-head CI;
   record the remaining native gate without claiming whole-plugin release GO.

Each worthwhile task is locally validated, committed, pushed and exact-head CI
verified. CI may run while the next safe repository slice is prepared; no task
counts complete until its own gate succeeds. A CI failure stops the batch.
No unrelated maintenance to meet a numeric target; no package/release/tag/deploy.

## Fixed candidate admission and ownership

Reuse the zero-row decoder's exact config and original20s virtual epoch/N8/v2
catalog. Only its ordinary-EOF synthetic capability mask0x00088209 is selected;
no downgrade of genuine features to fit it. Bind one distinct attempt/pair/
generation/request/session identity. Never reuse the old root/auth/capture/writer
registry as limited-session authority. Initial implementation may have intentionally
incomplete task-stage contracts; no native readiness before final reconciliation.

For session fixtures, pin a small MariaDB10.6-style greeting and 20-byte opaque
client authentication response for derived `alynt_ro_<seed>_i`, selected schema
local, charset45 and mysql_native_password. Check raw layout/length/sequence and
server-required/client-exact capabilities without retaining/reporting auth bytes.
Thread correlation alone is not authentication. Unsupported setup, cached/extended
metadata, TLS/compression, prepared/bulk/reconnect/extra session profiles refuse.
No general handshake framework or password validation is introduced.

Capture ordinary non-shared Buffers only, copying with fixed built-ins after
type/descriptor/size checks. Store private copies behind non-registered symbols;
no callback/dynamic parser/factory injection. Copy cap16KiB cumulative, pending
bytes16KiB, at most512 capture events, one selected exchange. These are model
bounds, not old transport limits or demonstrated native capacity. Five-frame
result grammar remains stricter than its defensive eight-frame ceiling.

One oldest outstanding credit at a time may receive an exact-length/equal-byte
forwarding acknowledgement and then observation. Release/zero private bytes on
success or refusal. Acknowledgement data must not alias/mutate private state.
An invalid operation latches refusal. Decoder completion must not ignore queued
data or infer transport EOF; terminal events are separate. Original epoch applies
to admission, capture, credit, observation, EOF and finish, with monotonic ticks.

Final receipt exposes frozen scalars only; all actual authentication/native/
forwarding/delivery/backing-absence/resource/storage/wiring/execution claims false.
Synthetic match requires real composition of the fixed decoder and session model,
not synthetic flags that bypass either. No ledger promotion in this batch.
