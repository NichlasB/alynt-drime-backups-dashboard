## Implemented boundary, not an application switch

[Guarded_Entry](../includes/class-source-policy-guarded-entry.php) now has
request_submit and request_view, returning ONLY projected errors, literal status
or the existing mode/revision view. No hook, route, form, caller, writer or global
request reader registers/invokes them. Existing create() factories remain closed.
The current application still uses its existing policy writer; no delivered lost-
update/authentication/HTTP or live-site readiness claim.

The [composition trait](../includes/traits/trait-source-policy-request-composition.php)
reuses the EXISTING capability→nonce→canonical fields/revision→exact record order.
The wrapper creates an inert local object first to avoid duplicating those guards;
it issues no assembly authority until after record admission. A static barrier is
consumed before guard callbacks, not only before provider invocation. The exact
Site_Repository is code-owned; no caller callback/repository/handle is accepted.
Definitions for the provider/context load only after the record check.

The root holds five fixed roles: connection, query, context, adapter, provider.
Each class's from_request method is compiled in its own scope, so it can legally
call new self and bind its private members. A private, unexported root identity
controls exact dependency identity, role order and a consumed construction lease.
PHP-public cross-class methods do not expose a factory: ordinary callers cannot
obtain an issued root. No public constructors, generic selector/service locator,
permit DTO, ready/facts/runtime setter, Reflection/Closure visibility bypass or
extra query/budget. Old isolated instance fixtures retain their existing path.

Context captures source before settings, then pushes its frozen private frame to
the exact root-bound receiver/query once. The receiver consumes its frame-attempt
bit BEFORE the source/settings callback comparison, and also refuses already-bound,
attempted, closed, ready or allocated state. No credential/descriptor getter was
added. Existing capture→actual initializer→active projection, source/query/receiver/
handle identity, report/session/schema/budget/revocation/uncertainty checks remain.
The same legacy/default/lab distinction and native timeouts/credits are unchanged.

Terminal root cleanup revokes assembly first, releases partial graphs, clears root
links/peers/catalog/site/owner references and restores the static barrier. Provider
continues to own actual operation cleanup and uncertain results. Root cannot clone,
serialize or restore. No operation graph or write-capable handle escapes in any
result. Private query leases are removed; the stock ambient placeholder callback
created by the admitted record query remains owned by core, not deleted as ours.
