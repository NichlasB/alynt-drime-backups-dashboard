## Decision: separate selected qualification worker, unchanged no-fault path

one private retained entry on its own exact pinned observation composition. No
public operation/getter, supplied owner/class/callable/handle, arbitrary worker
path, request/env/argv fault selector or production import. The existing isolated
worker stays unconditionally closed; existing native no-fault worker/runner/
protocol/source identities stay unchanged. Do not add a loss branch to them.

Before any future native bootstrap or fixture, perform declaration/source preflight
without WordPress, protected storage or native IO (bounded source-file reads only).
Before owner construction and immediately before entry,
verify the complete production/composition/projection and fixed worker manifest,
including original methods/signatures/traits/aliases/properties/defaults/constants.
Preserve the original five source digests and three no-fault native digests. Reject
changed/missing/extra declarations, unsupported layout or normalization that ignores
executable differences; no eval, source rewriting or caller-supplied alternate pins.

For selected construction reserve five additional compiled source groups:
`selected_worker,selected_channel,selected_supervisor,selected_relay,selected_registry`.
Their exact file memberships and reviewed canonical SHA256 values must be fixed
by the approved implementation before IPC; none exists or is claimed verified by
this design. Shared reused sources must be included in the owning dependency
group, not omitted because a top-level file is pinned. Avoid self-hashing generated
manifests; no source hashes accepted from remote messages as an authority input.

Actual root runs once, with real core authorization/current actor/borrowed auth,
separate small-issuance and privately constructed command nonce domains. Retain
exact guard order: small,small,small,small,small,command,small,command; one command
nonce creation. Wrong/malformed/stale/denied intent must still fail at its original
boundary, with no protected IO before authorization. No extra failure guards9/10,
reflected qualifier replay, return injection, clock refresh or source slot repair.

Use the existing callback7 writer handoff: capture closed, auth/writer distinct and
live, original pin retained,20 projections/zero writes, original remaining>=6s,
first4s and<=1s acknowledgement. Callback8 rechecks the same pin/state. Parent owns
fresh distinct attempt/root/pair labels and binds the exact actual writer role;
no synthetic pair or channel callback under row locks. Callback assertion failure
stays sticky and is rethrown outside the root's broad refusal catch: a swallowed
assertion must never masquerade as the expected false return.

## Selected loss and actual observation are independent conjuncts

Future single cut uses the existing narrow candidate: exact sequence0 COM_QUERY
`COMMIT AND NO CHAIN NO RELEASE`, credited original request write, same live owned
writer/root, clean parser/opposite boundaries and original remaining>=6s both at
request and complete response. Only complete sequence1 canonical seven-byte OK
payload `00 00 00 02 00 00 00`/11 framed bytes is eligible. Unsupported negotiation,
partial/extra/coalesced next packet, wrong frame/pair/credit, callback race, expired
reserve or a prior target write permanently disqualifies the candidate.

Before cut, ineligibility retains normal transparent forwarding subject to the
existing transport safety checks. After one atomic consume **before the sole
downstream write site**, never enqueue/replay those11 bytes and close only this
owned writer pair. No delayed replay, fabricated reply, injected mysqli result,
SQL KILL, server restart, reconnect/retry or compensating rollback. After cut,
exception/timeout/late callback cannot forward the response or rearm. Zero target
write attempts and completions must be observed, not inferred from bytesWritten,
socket destruction or error callbacks. No end(response)/graceful flush of loss bytes.

The original API must genuinely fail. Original source then closes/seals/qualifies
before finally erasure; selected worker must allow the actual false root result
to reach **private consumed extraction**, not no-fault require_root(true). It
must still independently refuse callback failure, source/clock/pin drift, missing
qualifier, missing return, exception/invalid receipt or nonempty original slots.
Consume/erase the projection before validation/serialization and discard private
references on every exit. Never clear original slots to manufacture evidence.

Expected actual selected result: one entry/one return, valid closed_array receipt,
history uncertain, current_acceptance_claimed=false, candidate_only=true and
request_lifecycle_closed_claimed=true. Preserve the actual client_release_claimed
boolean, including false; independent session disappearance cannot rewrite it.
diagnostic_candidate_only/authenticated/barrier_verified/closure_proven/retry/
storage/dispatch/execution flags remain false. A false release claim must be
reported as such and prevents any stronger claim of source-reported release;
it does not excuse unresolved physical cleanup. Original false/exception, erased
state or server OK alone never establishes that this actual result was observed.

The selected writer must **not** satisfy successful no-fault post-COMMIT drain/
forwarded-OK/QUIT. Preserve those predicates for no-fault. For selected writer,
exact cut replaces only that connection's successful-reply/drain expectation;
no validation query/reconnect is added after failure. All other traffic retains
its normal profile/order/equality. Require five equal streams; writer server
stream has equal forwarded prefix plus exactly one withheld11-byte suffix,
ingress=completed egress+withheld, pending0/unexplained0. Extra bytes/discard or
unaccounted QUIT fails this narrow candidate. Missing writer QUIT alone is not
cleanup proof or failure. Do not relax global stream equality with a generic loss flag.

## Reserved strict selected protocol, not an existing execution API

Reserve domain `alynt.qualification-observation.selected.v1`, version1, fixed
profile `qualification_selected_commit_response_loss`. Distinct from isolated-v1,
native-v1 no-fault, observation-v1 and selected-v2. No optional fields or selected
profile accepted by old parsers. Six successful frames, common ordered fields
`domain,v,kind,seq,attempt`, then only these additional fields in this order:

| Direction | Kind / seq | Additional fields |
|---|---|---|
| Parent -> worker | boot /1 | profile |
| Worker -> parent | root_request /1 | source |
| Parent -> worker | root /2 | root |
| Worker -> parent | bind /2 | root,auth,capture,writer,remaining_ns |
| Parent -> worker | bound /3 | root,writer,pair |
| Worker -> parent | final /3 | root,pair,profile,source,root_returned,pre_guards,post_guards,protected_reads,writes,original_slots_empty,observation |

`source` exact ordered keys: production,composition,projection,isolated_worker,
isolated_transcript,native_worker,native_channel,native_supervisor,selected_worker,
selected_channel,selected_supervisor,selected_relay,selected_registry. Each value
is64 lowercase hex; locally compiled values must match, not just message shape.
Labels are distinct64-hex; roles distinct positive uint32; remaining_ns canonical
decimal string6..10 billion. JSON canonical ASCII/LF/exact key order, no escapes,
duplicates/accessors/extra fields, depth8, frame<=4096 bytes including LF,
combined<=32768 bytes/six frames. Validate bounds before buffering/traversal.

Selected FINAL requires actual root_returned=false, pre_guards8/post_guards0,
protected_reads40/writes1, original_slots_empty=true, original exact9-field receipt
and13-field result with the selected semantics above. client_release_claimed is
a copied boolean, not a new classifier or default true. No native_proven,
authenticated or closure_proven=true flag. Same-instance source/receipt failures
cannot emit a success-shaped FINAL. Fixed bounded failure diagnostics are separate
non-authorizing output; never accepted as FINAL or missing values defaulted to pass.

Parent owns lifecycle/direction/order/labels and independently joins its selected
registry/transport result. A valid selected FINAL without the actual unique cut
is not selected proof; a cut without that FINAL is incomplete. Neither parser
authenticates its sender, proves genuine guards or yields a write-capable handle.
Never feed the external witness back into root/qualifier. Keep raw origin/rows/
cookie/nonce/SQL/auth payloads process-local and out of public summaries/logs.

## Time, ownership, independent completion and recovery

Preserve original real10s acceptance/UTC and conservative parent10s root envelope;
epochs are independent, never compare ticks across processes or reset started_ns.
Preserve connect3s/read5s/lock2s/metadata3s/socket-idle6s and6s selection reserve.
FINAL within original envelope; later cleanup cannot retroactively qualify expiry.
This immediate disconnect tests response loss, not five-second timeout/durability.

Keep2MiB frames/8MiB queued/64MiB attempt/4096 frames per pair; selected response
only11 owned bytes. Retain three roles within four-live/eight-accepted envelope.
No increasing caps to absorb unrelated prelude traffic. Original guard prelude
must independently exit/close/settle/audit before a fresh no-fault fixture lifetime;
fresh no-fault transparency/cleanup must pass before **one** separately approved
selected attempt on a third fresh fixture/relay lifetime. Historical success is
not a substitute for those same-source prerequisites. Failure/ineligibility stops;
no automatic retry or convenient second selected attempt.

After FINAL: end stdin once, actual stdout EOF/no trailing bytes, bounded stderr,
successful child exit AND close, pending writes settled/destroyed pipes, actual
listener/pair/pump closure. Preserve24s watchdog/28s cleanup policy,250ms graceful
pump join/1500ms transport join and90s outer backstop; timeouts mean unresolved,
never successful cleanup. Before any discard, prove the bounded cleanup mechanism
on prerequisite disposable children; do not close the live selected worker early
or treat a cleanup method call as observed descendant closure.
No unbounded server.close()/pipe wait, arbitrary PID/thread kill or dependency on
child exit alone. Parsing a final message does not discharge OS ownership.

Independent direct-backend audit after sessions absent: exact original pre-BEGIN
proposal stored, other nine rows unchanged, all ten owned locks available, borrowed
auth identity/state unchanged. No ledger repair before audit and no writer readback
after unknown COMMIT. Retain identities privately only for bounded audit/cleanup.
Then remove exact marker-owned users/tables and reconcile complete original table
inventory/checksums (historically77, resolve anew). Never drop unresolved-owned
fixtures or alter actual application users/options/cron; preserve precise owned
residue and report blocker if cleanup cannot be proved. Overall pass requires
every process/transport/witness/qualifier/audit/cleanup conjunct, not majority vote.
