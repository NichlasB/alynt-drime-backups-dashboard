## Why the existing selected worker cannot be reused unchanged

The legacy worker observes its original admission root returning false,8 pre-
guards/0 post-guards and an uncertain qualification; its registry accepts only
auth/capture/writer, at most three pairs, and restricts later traffic to QUIT.
Its10-second root and six-frame grammar cannot attest a subsequent native barrier.

The new native root releases the actual writer, invokes its original qualifier,
then may freshly authorize one barrier after committed OR uncertain history with
client_release_claimed=true. It erases full writer state before guard11. A valid
registered_closed result is an observation, NOT a client COMMIT acknowledgement,
durability guarantee, retry permission or authority. A real false result after
lost read authorization, timeout or failed close must remain false.

Keep the actual final class private native_entry_available() literal false before
authentication/IO. A future fixed CLI-only proof composition may enable only its
private entry and the explicitly enumerated passive seams below. No runtime
loader, public route, callback provider, arbitrary reflected target or fault-mode
argument is introduced. New composition/worker/source manifest, not edits to the
existing124-file no-fault proof manifest or legacy qualification identity.

## Passive observation without changing the original root

Alias the actual qualify_admission_outcome method under one fixed private name.
Invoke that alias exactly once even if observation fails; forward its exact return
or throw unchanged. Before/after observation uses bounded primitive validation
and the existing QualificationObservationProjection contract, never another
classifier. Require sealed cleanup, empty writer handles, equal capture digest
and unchanged IO counters. Retain only the nine-field projection receipt and its
original13-field closed qualification; no origin, proposal, pin, envelope or handle.
The closed-array qualifier remains candidate-only and barrier_verified=false;
the later native root result is a separate nine-field observation.

Add one fixed passive alias of open_lifecycle_session to record only its actual
mysqli thread ID and fixed capture/barrier phase after original factory/finally
completion. Require native mysqli, valid unsigned32-bit thread ID and exact
phase/boolean pairing; never retain a client or invoke user accessors. Original
arguments/result/throw remain unchanged; no SQL, clock, callback, IPC or added
native call in this seam. Admission writer identity is sampled at idle guard9.
This solves capture identity being erased before guard2 without reviving it.

Observation failures consume/invalidate the proof receipt, not change root flow
or skip the original source call. No receipt is supplied back into the root.
Extraction is one-shot AFTER root finally, original slot erasure and native
release; replay/reentry/source mismatch invalidates it. Manifest composition
checks must enumerate both aliases plus the private entry exception and compare
all other method origins/signatures/modifiers/traits/defaults/constants exactly.
Only enumerated new private primitive observation slots may differ; existing
state defaults and cleanup obligations cannot be replaced by test-owned success.

## Four roles, two idle bindings and unchanged guard order

One original borrowed auth session, one owned capture, one owned admission writer
and one distinct owned barrier: four roles/eight directional streams. Capture
closes before writer setup; writer closes and full writer state is erased before
guard11; barrier closes before DATA finish and guards23/24. No handle recycling,
reconnect, extra role or replacement auth session. Four unique server greeting
thread IDs must agree with the fixed worker's primitive identity observations.

| Phase | Required binding/continuity |
|---|---|
| Guard9, idle after writer metadata, before BEGIN | Bind auth/capture/writer; capture already closed, auth/writer live. ACK within1s; guard10 then freshly checks full mutation domain before any BEGIN/DML. No callback while rows are locked. |
| Guard11 through20 | Own actual closed-writer receipt, erased original writer slots and same borrowed actor/session/clock. Fresh observation intent/domains only; never imported authorization or external witness. |
| Guard21, idle after barrier metadata, before BEGIN | Bind the sole fourth pair to barrier using its passive factory observation; other role IDs immutable, capture/writer closed. ACK within1s; guard22 freshly checks full read domain before transaction. |
| Guards23/24 | Native barrier COMMIT/idle/close acknowledged, two metadata/two zero-DML inspections and DATA finish completed before fresh read guards. No IPC under barrier locks. |

Exact existing sequence, not configurable: M,M,M,M,M,MF,M,MF,M,MF,M,S,S,F,S,F,
S,F,S,F,S,F,S,F. M/MF are distinct small/full mutation domains; S/F are distinct
small/full observation domains. Observe nonce verification, not nonce creation;
no supplied filter result, cached guard certificate or newly minted permission.
Preserve40 admission projections,10 barrier projections and one ledger CAS max.

The NEW registry reserves only the fourth barrier role. Its handshake and bounded
fixed-profile setup may occur before guard21 binding; acceptance is provisional
until that binding confirms source identity and prior writer close. Before it,
any additional/reused pair or application command beyond the audited fixed idle

trace and necessary borrowed-auth checks are admitted, then normal owned cleanup.
The barrier COMMIT response is NEVER a loss target. Do not weaken the old registry's
three-role/QUIT-only policy or insert a general post-cut traffic exemption.

## Selected packet and clocks

Reuse exact parser/profile/credit primitives only if their unchanged contracts
fit. Select only the bound admission writer's COM_QUERY sequence0 command
COMMIT AND NO CHAIN NO RELEASE, after complete successful upstream write credit.
Require clean parser/opposite boundaries, no pending egress, and complete canonical
sequence1 OK payload00 00 00 02 00 00 00: exactly11 framed bytes, no extra packet,
tail or prior downstream attempt. Atomically consume eligibility BEFORE the sole
target write; discard those11 bytes, attempt/complete zero downstream target
writes, close only that owned writer pair. Never delay/replay, fake an API return,
kill SQL, restart services, repair/resend or issue compensating rollback.

Binding/request/completed OK must each be within the original admission's first4s
with at least6s remaining. Late eligibility, early OK before credited request,
partial/coalesced/extra packet or credit race permanently disqualifies selection;
pre-cut ineligible bytes remain transparent within transport limits. After a cut,
later failure cannot forward the withheld bytes, rearm or claim success.

No production clock/timeout change: original admission10s, read phase10s inside
original root20s, expiry/UTC nonregression; native connect3s/read5s, row lock2s,
metadata wait3s. These are acceptance limits, not hard server cancellation.
New parent uses an admission-selection deadline and a root-final deadline of20s
from its conservative ROOT grant, never a reset on cut, bind or observation.
Worker uses its actual original monotonic clock; do not compare raw process ticks.
Its durations and parent elapsed time must BOTH fit. Barrier ACK<=1s also consumes
the existing read/root budgets; expired root cannot be rescued by cleanup time.

Preserve4096 frames/pair,2MiB/frame,8MiB queued,64MiB/attempt,8 accepted/4 live
transport caps; semantic registry admits exactly four unique expected roles max,
not eight arbitrary roles. New registry must check all eight streams, not six.
Original24s watchdog/28s cleanup bound,250ms grace/1500ms transport join and90s
outer supervisor remain independent containment limits, not permission to extend
root acceptance. No automatic retry if any prerequisite/final predicate fails.

## New private protocol and acceptance conjunction

Proposed domain alynt.native-lifecycle-observation.selected.v1,version1; distinct
fixed no-fault/selected proof profiles, not additions to old selected grammar.
Eight ordered frames: parent BOOT1, child ROOT_REQUEST1, parent ROOT2, child
BIND_WRITER2, parent BOUND_WRITER3, child BIND_BARRIER3, parent BOUND_BARRIER4,
child FINAL4. Each direction has its own strict sequence. Exactly one of each;
no retry/duplicate/late frame, negotiation, extra key or alternative success form.
Canonical ASCII JSON/LF,4096 bytes/frame,32768 bytes/transcript, depth8 max;
reject partial EOF, duplicate keys, trailing bytes, noncanonical numbers/types.

Every frame has exact domain/version/kind/sequence/attempt fields. BOOT/ROOT bind
the fixed local source-group digests and profile; ACKs echo the exact preceding
role binding, never grant permission. BIND_WRITER has only three IDs and bounded
remaining duration; BIND_BARRIER adds only fourth ID and bounded remaining
read/root durations. No credentials, nonce/cookie, paths, SQL, raw handles, rows,
origin, proposal or runtime authority crosses stdio. Attempt IDs/digests are
correlation/integrity checks, NOT authentication/authorization certificates.
Specify exact field order/types/enums in the next synthetic schema implementation
before opening IPC; this design does not claim a parser or fabricated SHA exists.

FINAL carries only strict primitive projections of actual root result, exact
guard/domain/count checks, slot erasure and the once-consumed qualification
receipt. Parent derives relay accounting/cleanup independently, not from worker
assertions. Distinguish bounded diagnostic failure output from accepted FINAL;
redact details and never coerce failure into a successful observation.

Full selected success requires ALL of:

1. One original real COMMIT call returned false/threw, actual sent/unknown-ack
   capture, actual original qualifier historical_outcome=uncertain,
   client_release_claimed=true/current_acceptance_claimed=false, unchanged sealed
   capture and no observed IO within its passive wrapper. Client close alone is
   not server quiescence; a relay OK alone is not private outcome qualification.
2. Same root returns registered_closed/barrier_verified=true/candidate_only=false,
   all six authority/closure/retry/storage/dispatch/execution flags false; exact24
   guards/four domains,40+10 projections/one CAS/two metadata/two zero-DML checks.
   Original writer erased before guard11, fresh barrier closed before guards23/24,
   all root slots erased on return. False/throw is never repaired into this array.
3. Independent selected witness: upstream request credit complete, exact11-byte
   withheld suffix, no selected response downstream attempt, selected writer
   close; all other seven streams equal and the selected stream equal-prefix
   plus sole withheld suffix. No global expected-loss accounting waiver.
4. Independent owned-ledger read equals the original pre-DML proposal; other nine
   safety/settings rows unchanged; known sessions absent, owned locks available,
   all application inventory/checksums unchanged and previewed owned cleanup done.
   No success just from matching stored rows or no longer seeing a client slot.

If read authorization/time/release fails after real uncertainty, report only
the independently established limited facts and an incomplete/failed joined
proof. Do not claim registered_closed, durability, safe retry or execution.
