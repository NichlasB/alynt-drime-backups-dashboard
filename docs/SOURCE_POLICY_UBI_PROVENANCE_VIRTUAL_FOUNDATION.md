## Separate dormant model; no real alias consumer

`source_policy_virtual_closure.py` accepts exact primitive identity/layer/node
records and optional **synthetic** alias profile DATA. It imports no IO/process
module, has no host-path resolution, and is not imported by the reader, fixed UBI
entry, workflow or plugin bootstrap. `real_aliases()` remains empty; default
model profiles have no aliases. Synthetic profiles do not mint a real permission.

Each layer requires sequential ordinal, expected compressed+diffID hashes and
both strict verified flags before atomic virtual commit. Duplicate/bad entries
discard the staged layer. Explicit/opaque whiteouts affect lower nodes before
same-layer additions regardless of marker order; replaced non-directories remove
descendants while directory metadata updates preserve children. Initial subset
rejects hardlinks/special files and archive writes through non-directory parents;
it does not claim general OCI overlay/extraction compatibility.

Finalization occurs only after all expected layers, hashes identity/profile/tree
provenance, and makes the snapshot immutable. Later apply/finalize refuses, so no
path-only cache can survive a late change. Selected path resolution checks every
directory/origin, exact listed symlink type/target/layer/entry, image-root lexical
target containment, cycle/hop bounds and terminal regular-file identity. Absolute
targets are virtual image-root DATA, never host paths. Proc/sys/dev selections,
escaping/dangling/unlisted links and set-ID selected files refuse.

The optional graph operation validates supplied object hashes against resolved
file origins, exact primitive provider/needed shapes, unique provider names,
interpreter object presence, no search-path features and bounded acyclic edges.
These supplied ELF descriptors are synthetic DATA, not parsed candidate proof.
DT_NEEDED graph success always reports model_onlytrue/runtime_grantfalse and
runtime_profileunestablished. It cannot establish NSS/FIPS/dlopen/plugin/shutdown
objects, real mapped-library closure or authorize version execution.

Caps:10 layers,65536 cumulative entries/nodes,240-byte canonical keys/32 components,
