  Private frame/source/context bindings default absent; there is no production
  provider, public initializer, imported handle, caller SQL/callback, activation
  switch or environment-selected test backend. All public factories still
  return unavailable; db_connect/check_connection remain final refusals.
- Settings/source/observer admission precedes object initialization/allocation.
  Finite database/table/endpoint/credential/charset DATA, numeric loopback,
  explicit port/database, flags0 and known single-site/core-cache/no-drop-in
  posture are required. Unknown setup observers refuse without invocation or
  autoload; `all` and incompatible_sql_modes must be empty even when their
  privately expected fingerprints match. Both now belong to ongoing hook seals.
- The attempt latch is consumed before the one object-only parent constructor.
  Its virtual db_connect still refuses; mysqli selection, no handle, no query
  and ready=false are checked afterward. No core-private driver flag is stamped.
  Existing exact owned callback warm-up/sealing runs before driver allocation.
- One internally allocated handle is retained independently of dbh. Required
  connect2s/read3s/local-infile-off options must acknowledge before one explicit
  real_connect call. Allocation, failed connection and connected-unqualified
  states cannot be represented as never-opened or active by missing flags.
- A finite, ordered private catalog checks selected database/autocommit/no
  transaction, sets only fixed own-session limits, invokes inherited charset/
  mode helpers, then validates session/table/column/index metadata. Helpers are
  followed immediately by native error checks. There is no public SQL setup
  channel, parent connector, copied query executor, retry or reconnect.
- Metadata is bounded to the fixed shapes (at most5 column/4 index rows,
  11 fields,64-byte field names/1024-byte values; mode32 unique bounded tokens).
  Sixteen command-effect credits reserve helper effects, independently of
  capability calls. Twenty-second monotonic checks do not interrupt blocked
  synchronous operations and are not a proven hard process deadline.
- Frozen source/handle/global identity and callback seal are rechecked across
  steps and after preparation. Facts derive from observed DATA internally;
  qualification/state/ready publish last, without a callback between the final
  check and publication. Ordinary dispatch remains unavailable before that.
- All metadata results are freed in finally. Failure blocks dispatch, attempts
  exact partial/active driver release once and independently releases the owned
  callback lease. Foreign/global handles and callbacks are preserved. Unknown
  close/removal returns cached false, never a fabricated cleanup success.
  Scoped native diagnostic handlers restore the prior handler; public failure
  is the fixed unavailable code, without raw diagnostic/SQL/credential output.
  The frame/binding/password fields are cleared on terminal bootstrap paths.
