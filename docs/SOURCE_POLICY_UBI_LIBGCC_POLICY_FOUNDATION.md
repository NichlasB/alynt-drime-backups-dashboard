## Implemented private seam and preserved behavior

The ELF module contains one fixed policy tuple from the captured evidence:
`libgcc_s.so.1` at `usr/lib64/libgcc_s.so.1`, layer0/entry1700, targeting exactly
`libgcc_s-11-20240719.so.1`, with the design's target-string SHA, image/config,
ten ordered compressed-layer identities and alias-layer diffID. There is no
wildcard, date/version regex, caller allowlist or target-body SHA invention.
The current library validator remains unchanged.

`_candidate_alias_frame` admits an exact nine-key private `ADBUCAP1` DATA context:
format/profile, manifest/config, head/run/source/snapshot and ten tuple layer
pairs. It rejects JSON, lists, arbitrary objects, unknown fields, malformed
types/lengths and changed fixed pins/plan. Other diffIDs must match the already
held owner/model plan; their genuine config admission remains the real entry's
responsibility. No dictionary or context alone grants actual candidate authority.

`_CandidateAliasPolicy` retains one immutable primitive frame and the source-held
tree/owner references, not a caller-mutable registry. Every graph/provider use
requires the exact current module's private policy type, original tree identity,
both owner/model directions, complete finalized ten-layer state, identities/run/
layer plan/current snapshot and the same deadline. Original phase/clock checks
reject poisoned or closed owners. Each admission charges a fixed32 shared model
work units; no new allowance, reset, replay or uncharged body parse is introduced.
This is source-level DATA admission, **not** process isolation or job attestation.

The provider still validates requested names before any lookup. With no profile,
it keeps the strict numeric rule and original finite refusal/diagnostic behavior.
With a valid profile, **library validity and non-self targeting remain mandatory
outside both branches**; only the exact observed tuple may replace prefix/suffix
requirements. The pure tuple matcher requires the exact inspected symlink-row
shape, bounded primitive metadata, model-only/no-grant flags and current snapshot.
All choices occur before a terminal refusal: no catch/poison/resume fallback.
Invalid profile/context refuses before protected inspection; a rejected alias
performs one alias inspection and never follows its target.

After admission, the existing single target inspection, regular/mode/combined-link
checks, owner retained-origin check, metadata SHA/size/origin, same snapshot,

The fixed `_owned_graph` helper has a keyword-only default-None context seam.
