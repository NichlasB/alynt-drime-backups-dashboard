## Fixed profile and separate control path

The existing manual workflow adds boolean `alias_policy`, defaultfalse. Its two
literal branches select strict or exception CLI flags; malformed mode values
refuse. The CLI checks environment/flag agreement in addition to the existing
exact master head/repository/workflow/OS/run admission. Normal mode still calls
the unchanged shared `scan_layer` and retains both critical symlink refusals.
The shared reader's bytes/guards/default acceptance are unchanged.

Exception mode imports a separate `source_policy_ubi_alias_static.py`. Before
each gzip scan it independently checks the complete compressed file size/SHA256.
It reads bounded regular-file bodies into hashes, not retained content buffers,
and collects primitive metadata/whiteout records without extracting anything.
It preserves the shared path grammar, Unicode15.0, sparse/PAX/type/duplicate,
entry/expanded/member/deadline limits. Hardlinks/specials, invalid link targets,
non-file bodies and unsupported archive shapes refuse conservatively. No staging
record returns until the entire gzip stream/diffID verifies; failures cannot
commit partial model state. Failure diagnostics are bounded name/target summaries,
not raw archive/body/URL/token dumps, and never authorize continued collection.

Actual candidate manifest/config and all ten compressed descriptors remain fixed
by the original entry's verified metadata admission. First-layer profile requires
exact `lib64`, symlink type, literal `usr/lib64`, layer0 and observed global archive
entry659. Its canonical-record index is mapped only after that full layer verifies;
it is distinct from the archive ordinal, which may include ignored root entries.
The model identity binds the fixed manifest/config and full frozen source cohort.
Neither candidate input, receipt nor caller supplies another accepted edge.

All layers commit in order under the existing virtual work/entry/node/layer/time
caps. Whiteout/replacement invalidation and immutable final snapshot precede
selected resolution. A later changed alias origin, unapproved leaf symlink,
hardlink, special root, escape, unresolved parent/target or budget exhaustion
remains a refusal. The only new consumer is this explicitly selected static mode;
`real_aliases()` and all default/runtime consumers remain empty/disconnected.

The selected-origin receipt is namespace/content-hash DATA. It does not parse a
complete candidate ELF graph or establish DT_NEEDED/NSS/FIPS/dlopen/plugin/shutdown
closure. `runtime_grantfalse`, runtime feasibility not-run and dependency closure
